Exception Handling in Python

Keep your program running when something goes wrong.

Without handling

print(10 / 0)
print("Next line")
Output
ZeroDivisionError: division by zero

The program stops. "Next line" never runs.

With try and except

try:
    print(10 / 0)
except:
    print("Cannot divide by zero")
print("Next line")
Output
Cannot divide by zero
Next line

The program survives and continues.

Error or exception?

Syntax error Python finds it before running. Nothing runs at all.

print("Hello"
Output
SyntaxError: '(' was never closed

Exception The code is correct, but it fails while running.

num = int("abc")
Output
ValueError: invalid literal for
int() with base 10: 'abc'
Exception handling is only for exceptions. We fix syntax errors by correcting the code.

Why do we need it?

An ATM does not break when you type a wrong PIN. It shows a message and lets you try again. Our programs should do the same.

age = int(input("Enter age: "))
print("Next year:", age + 1)
print("Thank you")
Output
Input: abc
ValueError: invalid literal for
int() with base 10: 'abc'
Line 2 and line 3 never run. One wrong input crashes the whole program.

try and except

Put risky code in try. If an exception happens, Python jumps to except.

try:
    age = int(input("Enter age: "))
    print("Next year:", age + 1)
except:
    print("Please enter a number")
print("Program continues")
Output
Input: abc
Please enter a number
Program continues
Output
Input: 20
Next year: 21
Program continues
If try has no exception, the except block is skipped.

Catch specific exceptions

Use one except for each kind of problem. Each one gives its own message.

try:
    a = int(input("Enter a: "))
    b = int(input("Enter b: "))
    print("Result:", a / b)
except ValueError:
    print("Enter whole numbers only")
except ZeroDivisionError:
    print("b cannot be zero")
Output
Input: 10 and 0
b cannot be zero
Output
Input: ten
Enter whole numbers only
A bare except: hides which error happened. Prefer a named exception.

Read the message with as e

Python gives every exception a message. Store it in a variable and print it.

marks = [70, 80, 90]
try:
    print(marks[5])
except IndexError as e:
    print("Error:", e)
Output
Error: list index out of range
try:
    price = {"pen": 10}["book"]
except KeyError as e:
    print("Missing key:", e)
Output
Missing key: 'book'

else runs when nothing went wrong

try:
    n = int(input("Enter number: "))
except ValueError:
    print("Not a number")
else:
    print("Square is", n * n)
Output
Input: 4
Square is 16
Output
Input: abc
Not a number
Rule: else runs only if try finished with no exception.

finally always runs

Use it for cleanup work, like closing a file, that must happen in every case.

try:
    f = open("data.txt")
    print(f.read())
except FileNotFoundError:
    print("File not found")
finally:
    print("Done")
Output
data.txt does not exist
File not found
Done
With an error or without an error, finally runs both times.

raise your own exception

Sometimes the input is a valid number but still wrong for our rule. We raise the error ourselves.

try:
    age = int(input("Enter age: "))
    if age < 18:
        raise ValueError("Age must be 18 or more")
    print("Welcome")
except ValueError as e:
    print("Error:", e)
Output
Input: 15
Error: Age must be 18 or more
Output
Input: 25
Welcome

Catch many exceptions in one line

If two exceptions need the same message, put them in a tuple (round brackets).

try:
    n = int(input("Enter number: "))
    print("Result:", 100 / n)
except (ValueError, ZeroDivisionError):
    print("Invalid input")
Output
Input: abc
Invalid input
Output
Input: 0
Invalid input
Output
Input: 4
Result: 25.0
except Exception as e catches almost every error. Use it as the last choice and print e to see what happened.

Ask again until the input is valid

Put try inside a while True loop. The break runs only if int() worked.

while True:
    try:
        age = int(input("Enter age: "))
        break
    except ValueError:
        print("Wrong input, try again")
print("Age is", age)
Output
Input: abc, then 25
Wrong input, try again
Age is 25
A wrong value skips break, so the loop asks again.
